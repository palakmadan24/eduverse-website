# eduverse-website# EduVerse University Website

EduVerse is a responsive university website created using HTML and CSS.

## Features
- Home page with hero section
- Courses section with slider
- About Us page
- Contact Us page
- Blog section
- Responsive design
- Footer with newsletter subscription

## Technologies Used
- HTML5
- CSS3
- JavaScript (optional)

## How to Run Locally
1. Download or clone the repository.
2. Open index.html in a browser.
