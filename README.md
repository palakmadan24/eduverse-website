                        🎓 EduVerse University Website

EduVerse is a responsive university website built using HTML, CSS, and JavaScript.
It showcases academic programs, campus life, student testimonials, placements, and a contact system in a modern and user-friendly layout.

📌 Features

1. ✅ Fully responsive design (desktop, tablet & mobile)

2. 🎯 Hero section with call-to-action

3. 📚 Courses & programs showcase

4. 🏫 Campus gallery

5. 💬 Student testimonials

6. 📞 Contact form

7. 📊 Placement highlights

8. 📱 Mobile navigation menu

9. 🎨 Clean UI & smooth animations


🛠️ Technologies Used


1. HTML5

2. CSS3 (Flexbox & Grid)

3. JavaScript (Vanilla JS)

4. Google Fonts

5. Font Awesome Icons
